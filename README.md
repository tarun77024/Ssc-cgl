# SSC CGL 2027 Planner - installable web app (PWA)

## Put it online (free, 2 minutes)
- Easiest: go to https://app.netlify.com/drop and drag this whole `ssc-cgl-pwa` folder in. You get an https link.
- Or use GitHub Pages / Cloudflare Pages / Vercel. It must be served over https.

## Install on iPhone
1. Open the https link in **Safari** (not Chrome).
2. Tap Share, then **Add to Home Screen**.
3. Open it from the Home Screen icon. Go to More, tap **Enable notifications**, then **Add daily reminder to Calendar (.ics)** for guaranteed alarms.

Notes: notifications need iOS 16.4+ and the Home Screen install. A web app cannot fire reminders while fully closed without a push server, so the Calendar alarms are the reliable option.
Your progress is saved on the phone. Use More > Export data to back it up.
